# Click Sales Notify

Plugin WordPress de uso pessoal: registra o gclid, recebe postbacks de redes de afiliado, avisa vendas (Telegram/Discord/e-mail/WhatsApp) e exporta conversões offline para o Google Ads.

## Publicar uma nova versão
1. Suba os arquivos atualizados neste repositório.
2. Confirme que `Version:` no `click-sales-notify.php` e `CSN_VERSION` têm o mesmo número (ex.: 1.2.0).
3. Em **Releases → Draft a new release**, crie a tag `v1.2.0` e publique.
4. O GitHub Actions anexa `click-sales-notify.zip` na release em ~1 minuto.
5. Nos sites, em até 12h aparece **Atualizar agora** em Plugins (ou use Click Sales → Configurações → Verificar atualizações agora).
